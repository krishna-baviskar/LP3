# Practical 1: MetaMask installation and Ether transaction fee study

This is a wallet/network exercise, not a Solidity coding practical.

1. Install MetaMask only from its official website or browser/mobile app store.
2. Create a wallet and securely back up the Secret Recovery Phrase offline. Never share it.
3. Switch to a test network (for example, Sepolia) and obtain test ETH from a reputable faucet.
4. Send a small test transaction to another test wallet.
5. Open the transaction in the network explorer and record: transaction hash, gas used, gas price, and transaction fee.
6. Fee in ETH = gas used × effective gas price (in ETH per gas unit).
7. Do not use real funds for classroom experiments. Never enter a recovery phrase into a website or share it with anyone.
