# Practical 2: Create a wallet using MetaMask

1. Install MetaMask from the official source.
2. Select Create a new wallet and set a strong local password.
3. Write the Secret Recovery Phrase on paper and store it securely offline.
4. Confirm the phrase in MetaMask. Do not take screenshots or share it.
5. Copy the public wallet address for receiving test tokens.
6. Switch to a test network and receive test ETH from a faucet.
7. Verify the received transaction using the block explorer.

Security: anyone with the Secret Recovery Phrase can control the wallet. Never share it.
